# IQanat HH Bot

Telegram-бот для поиска соискателей из базы выпускников. Данные хранятся в Google Sheets, авторизация — по ключу доступа, статистика — в локальной SQLite базе.

---

## Возможности

- 🔐 **Авторизация по ключу доступа** — ключи хранятся в Google Sheets (вкладка «Реестр»), после первого входа повторная авторизация не требуется
- 🔍 **Поиск с фильтрами** — Направление → Специальность (2 этапа), ВУЗ, Область, Район, Пол
- ⭐ **ТОП кандидаты** — отображаются первыми в списке с пометкой
- 📥 **Скачивание резюме** — поддержка Google Docs, Google Sheets (.xlsx), Google Drive файлов
- 📦 **Скачать всё** — пакетная загрузка с прогрессом
- 📊 **Статистика для админов** — какие фильтры использовались, какие резюме скачивались

## Структура таблицы Google Sheets

### Вкладка `Аламни`

| Колонка | Тип | Описание |
|---|---|---|
| ФИО | текст | Полное имя |
| Пол | текст | Мужской / Женский |
| Город | текст | |
| ВУЗ | текст | Название университета |
| Направление | текст | Укрупнённое направление (1-й этап фильтра) |
| Специальность | текст | Специальность (2-й этап фильтра) |
| Область | текст | |
| Район | текст | |
| Резюме | ссылка | Google Docs / Sheets / Drive |
| ТОП | текст | `Да` — выделяется в списке звездой ⭐ |

### Вкладка `Реестр`

Первый столбец — список допустимых ключей доступа.

## Установка

### 1. Клонировать репозиторий

```bash
git clone https://github.com/your-username/IQanat_hh_bot.git
cd IQanat_hh_bot
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

### 3. Настроить Google Sheets API

1. Открыть [Google Cloud Console](https://console.cloud.google.com/)
2. Создать проект → включить **Google Sheets API** и **Google Drive API**
3. Создать сервисный аккаунт → скачать ключ в формате JSON
4. Переименовать файл в `credentials.json` и положить в папку проекта
5. В Google Sheets → **Настройки доступа** → добавить email сервисного аккаунта с правом **Читатель**

### 4. Создать `.env` файл

```bash
cp .env.example .env
```

Заполнить значения:

```env
BOT_TOKEN=токен_от_BotFather
SPREADSHEET_ID=id_таблицы_из_URL
CREDENTIALS_FILE=credentials.json
ADMIN_IDS=123456789,987654321
DB_FILE=iq_hh_bot.db
```

> `SPREADSHEET_ID` — часть URL таблицы:
> `https://docs.google.com/spreadsheets/d/`**`ВОТ_ЭТО`**`/edit`

> `ADMIN_IDS` — Telegram user_id через запятую. Узнать свой id можно у бота [@userinfobot](https://t.me/userinfobot)

### 5. Запустить

```bash
python main.py
```

## Использование

### Для пользователя

| Действие | Описание |
|---|---|
| `/start` | Запустить бота. При первом входе запросит ключ доступа |
| 🔍 Поиск соискателя | Открыть меню фильтров |
| Выбор фильтра | Показывает уникальные значения столбца |
| ❌ Сбросить фильтр | Нажать на активный фильтр для сброса |
| 👥 Показать соискателей | Список найденных кандидатов с учётом всех фильтров |
| Имя в списке | Скачать резюме конкретного кандидата |
| 📥 Скачать всё | Скачать резюме всех найденных кандидатов с прогрессом |

### Для администратора

```
/admin — вывод статистики:
  • какой ключ доступа какие фильтры применял и сколько раз
  • какие резюме скачивались и сколько раз
```

Администраторы назначаются через `ADMIN_IDS` в `.env`.

## Кэширование

Данные из Google Sheets кэшируются локально, чтобы не превышать лимиты API:

| Вкладка | TTL |
|---|---|
| Аламни (соискатели) | 5 минут |
| Реестр (ключи доступа) | 1 минута |

---

## Поддерживаемые форматы резюме

| Тип ссылки | Поведение |
|---|---|
| `docs.google.com/document` | Экспорт в PDF, при ошибке — скачивание как .docx |
| `docs.google.com/spreadsheets` | Экспорт в .xlsx, при ошибке — прямое скачивание |
| `drive.google.com/file` | Прямое скачивание файла |

Все запросы к Google выполняются через авторизованную сессию сервисного аккаунта.
