# IQanat HH Bot

Telegram-бот для поиска соискателей из базы выпускников IQanat. Данные берутся из Google Sheets, авторизация — по БИН попечителя, статистика автоматически выгружается обратно в таблицу.

---

## Возможности

- 🔐 **Авторизация по БИН** — после первого входа повторно вводить не нужно
- 🔍 **Поиск с фильтрами** — Специальность, ВУЗ, Область, Район, Пол. Можно комбинировать
- ⭐ **ТОП кандидаты** — отображаются первыми в списке с отметкой
- 📥 **Скачивание резюме** — по одному или все сразу с прогресс-баром
- 📊 **Автоотчёты в Google Sheets** — фильтры и просмотры резюме записываются в таблицу каждые 10 минут
- 🛠 **Команда `/admin`** — сводная статистика по попечителям прямо в чате

---

## Структура Google Sheets

Бот работает с одной таблицей. В ней должны быть следующие вкладки:

### `Аламни` — база соискателей

| Колонка | Описание |
|---|---|
| ФИО | Полное имя |
| Пол | Мужской / Женский |
| Город | |
| ВУЗ | |
| Направление | Укрупнённое направление |
| Специальность | |
| Область | |
| Район | |
| Резюме | Ссылка на файл (Google Docs, Sheets, Drive) |
| ТОП | Введите `Да` — соискатель попадёт в топ списка со звездой ⭐ |

### `Реестр` — список доступа

| Колонка | Описание |
|---|---|
| БИН | Ключ доступа для входа в бота |
| Попечитель | Имя попечителя (отображается в статистике) |

### `Отчет по фильтрам` — автозаполняется ботом

| Попечитель | User_id | Категория | Фильтр |
|---|---|---|---|

### `Отчет по ФИО` — автозаполняется ботом

| Попечитель | User_id | Соискатель | Статус |
|---|---|---|---|

> Заголовки в листах отчётов должны совпадать точно — бот дописывает строки ниже.

## Установка

### 1. Клонировать репозиторий

```bash
git clone https://github.com/temirgaukhov/IQ_hh_bot.git
cd IQ_hh_bot
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

### 3. Настроить Google Sheets API

1. Открыть [Google Cloud Console](https://console.cloud.google.com/)
2. Создать проект → включить **Google Sheets API** и **Google Drive API**
3. Создать сервисный аккаунт → скачать ключ в формате JSON
4. Переименовать файл в `credentials.json` и положить в папку проекта
5. В Google Sheets → **Настройки доступа** → добавить email сервисного аккаунта с правом **Редактор**

### 4. Создать `.env` файл

```bash
cp .env.example .env
```

Заполнить:

```env
BOT_TOKEN=токен_от_BotFather
SPREADSHEET_ID=id_таблицы_из_URL
CREDENTIALS_FILE=credentials.json
ADMIN_IDS=123456789,987654321
DB_FILE=iq_hh_bot.db
```

> **SPREADSHEET_ID** — часть URL таблицы:
> `https://docs.google.com/spreadsheets/d/`**`ВОТ_ЭТО`**`/edit`

> **ADMIN_IDS** — Telegram user_id через запятую. Узнать свой id: [@userinfobot](https://t.me/userinfobot)

### 5. Запустить

```bash
python main.py
```

## Инструкция для пользователя

| Шаг | Действие |
|---|---|
| 1 | Отправить `/start`, ввести БИН при первом входе |
| 2 | Нажать **🔍 Поиск соискателя** |
| 3 | Выбрать нужные фильтры. Каждый последующий фильтр сужает список |
| 4 | Нажать **👥 Показать соискателей — N чел.** |
| 5 | Нажать на имя — получить резюме. Или **📥 Скачать всё** |

Активный фильтр можно сбросить, нажав на него повторно.

## Инструкция для администратора

### Команда `/admin`

Показывает в чате:
- Какой попечитель (и его Telegram user_id) какие фильтры применял и сколько раз
- Какие резюме просматривались и сколькими пользователями

Доступ к команде — только для user_id из `ADMIN_IDS` в `.env`.

### Отчёты в Google Sheets

Бот автоматически каждые 10 минут дописывает строки в два листа:

**`Отчет по фильтрам`** — каждое применение фильтра:
- Попечитель, Telegram user_id, категория фильтра, выбранное значение

**`Отчет по ФИО`** — каждый просмотр резюме (уникально на пользователя):
- Попечитель, Telegram user_id, ФИО соискателя, статус «Просмотрен»

> Один попечитель может работать с нескольких аккаунтов Telegram — каждый отображается отдельной строкой.

### Добавить администратора

Открыть `.env`, добавить Telegram user_id через запятую:

```env
ADMIN_IDS=123456789,987654321,555000111
```

Перезапустить бота.

### Добавить нового попечителя

В Google Sheets открыть вкладку **Реестр**, добавить строку:

| БИН | Попечитель |
|---|---|
| 123456789012 | Иванов Иван |

Бот подхватит изменение автоматически (обновление раз в минуту).

## Развёртывание на новом сервере

```bash
git clone https://github.com/temirgaukhov/IQ_hh_bot.git
cd IQ_hh_bot
pip install -r requirements.txt
```

Скопировать вручную в папку проекта:
- `.env` — настройки
- `credentials.json` — ключ Google API
- `iq_hh_bot.db` — база данных (если нужно сохранить историю авторизаций)

```bash
python main.py
```

## Важно перед публикацией в репозиторий

Файлы `.env`, `credentials.json` и `iq_hh_bot.db` **нельзя коммитить** — они перечислены в `.gitignore`. Передавать только вручную.
